# base2048

[qntm's base2048](https://github.com/qntm/base2048): 11 bits per character from 2,048 code points below U+1100, decoded strictly and canonically.

```python
from radixly import base2048

base2048.encode(b"hi")        # 'ڵՈ'
base2048.decode("ڵՈ")         # b'hi'
base2048.encode(b"\x00")      # 'F': a short payload can be plain ASCII
```

## Alphabet

Letters and numerals from two dozen scripts, none above U+10FF, built for Twitter, which counts every code point from U+1100 upward as two. No whitespace, control, punctuation, symbol or combining characters, stable under every normalization form. A leftover of 1 to 3 bits takes a short character from a second alphabet of 8; a final character carrying no payload bits is rejected.

::::{grid} 1 2 2 2
:gutter: 2

:::{grid-item-card} Use it for
Channels that count characters but frown on the high end of the BMP or on the supplementary planes, and places where the text should read as letters rather than a wall of ideographs.
:::

:::{grid-item-card} Reach for another codec when
the channel takes the whole BMP: {doc}`base32768` carries a third more. As UTF-8 most characters cost two or three bytes.
:::

::::

## Truncation

No length and no checksum: after `k` characters the `11 * k mod 8` leftover bits must look like padding. Just under a quarter of cuts pass, to a prefix; the rest raise {class}`~radixly.DecodeError` at the last character.

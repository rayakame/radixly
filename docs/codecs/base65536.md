# base65536

[qntm's base65536](https://github.com/qntm/base65536): every pair of bytes becomes one code point, the densest codec here.

:gutter: 2

:::{grid-item-card} 2 → 1

passes a truncation check
:::

```python
from radixly import base65536

base65536.encode(b"hi")        # '鹨'
base65536.decode("鹨")          # b'hi'
base65536.encode(b"hi!")       # '鹨ᔡ': the odd byte's own block
```

## Alphabet

256 blocks of 256 consecutive code points; the second byte of a pair picks the block, the first the offset. Every character is assigned, non-combining and stable under normalization, with no whitespace or control characters. Most blocks lie outside the Basic Multilingual Plane, so most characters are surrogate pairs in UTF-16.

::::{grid} 1 2 2 2
:gutter: 2

:::{grid-item-card} Use it for
Channels that count code points and accept the supplementary planes.
:::

:::{grid-item-card} Reach for another codec when
the channel counts UTF-16 code units (an astral character is two, so 8 bits per unit) or strips astral characters: {doc}`base32768` is the safer choice. As UTF-8 most characters cost four bytes.
:::

::::

## Truncation

Every prefix is itself valid: a string cut after `k` characters decodes, without an error, to the first `2 * k` bytes. There is no padding, no length and no checksum to object.

# base32768

[qntm's base32768](https://github.com/qntm/base32768): 15 bits per character from 32,768 BMP code points, decoded strictly and canonically.

```python
from radixly import base32768

base32768.encode(b"hi")        # '媔ʟ'
base32768.decode("媔ʟ")        # b'hi'
base32768.max_bytes(100)       # 187
```

## Alphabet

32,768 code points qntm picked for survival: no whitespace, no control or format characters, no combining marks, no surrogates, nothing unassigned, all stable under every Unicode normalization form. The text looks like a wall of CJK and Hangul and comes through chat messages, database columns and normalizing frameworks unchanged. A leftover of 1 to 7 bits takes a short character from a second alphabet of 128; a final character carrying no payload bits is rejected, which is stricter than qntm's decoder.

::::{grid} 1 2 2 2
:gutter: 2

:::{grid-item-card} Use it for
Anything that limits you by character count: a form field, a capped identifier, a file name. Two and a half times base64's payload per character.
:::

:::{grid-item-card} Reach for another codec when
the channel counts bytes (as UTF-8 each character costs three), counts UTF-16 code units and accepts astral characters ({doc}`base65536`), or must catch a truncation ({doc}`uro14`).
:::

::::

## Truncation

No length and no checksum: after `k` characters the `15 * k mod 8` leftover bits must look like padding, which they always do on every eighth cut and otherwise by chance. Just under a quarter of cuts pass, to a prefix; the rest raise {class}`~radixly.DecodeError` at the last character.

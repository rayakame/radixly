# base32768

15 bits per character from 32,768 BMP code points — qntm's specification,
decoded strictly and canonically.

## When to use it

The densest codec: 187 bytes fit in 100 code points. Choose it when the
channel counts code points and the alphabet's breadth is acceptable.

## Truncation behavior

About half of all truncations decode without error to a prefix of the
original payload — see {doc}`../guides/truncation`.
